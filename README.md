# mk-merc.github.io | Developer Portfolio

## Getting Started

### Prerequisites

* Node.js

### Installation

1. Clone the repo

2. Setup the frontend

```
cd frontend
npm install
```

3. Start the server

```
npm run dev
```

## Deployment

The portfolio is deployed using GitHub Pages.

## Built With

* [Vite](https://vite.dev/guide/) - Development Server
* [Typescript](https://www.typescriptlang.org/) - Type-safe JavaScript
* [React](https://react.dev/learn) - Frontend Library
* [Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite) - Styling and UI Design
